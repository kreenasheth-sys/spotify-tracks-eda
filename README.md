# Spotify Tracks EDA

Exploratory Data Analysis of Spotify tracks using Python.

## Analysis Includes
- Data cleaning and exploration
- Univariate analysis
- Histograms and boxplots
- Correlation heatmap
- Analysis of audio features such as danceability, energy, popularity and acousticness

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
