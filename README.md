# Spotify Tracks EDA

Exploratory Data Analysis of Spotify tracks using Python to understand track characteristics, popularity, and relationships between audio features.

## What I Explored

- Data quality checks, missing values, and duplicates
- Distribution of audio features such as danceability, energy, and popularity
- Histograms and boxplots for univariate analysis
- Correlations between numerical audio features
- Relationships between acousticness, energy, and track genres

## Key Insights

- More energetic tracks tend to have higher loudness.
- Energy and acousticness show a strong negative relationship.
- Most tracks have relatively low to moderate popularity, with highly popular tracks being less common.
- The analysis also explores how audio characteristics vary across selected music genres.
